One emoji for the trip of my dreams: Mount Fuji 🗻. A program that writes a single emoji to `/output/entry.txt` for make.fun's "One Emoji, One Dream Vacation" bounty — one particular dream (Japan, Fuji), not any holiday.

## Run it

```sh
python3 main.py
```

Writes one emoji (U+1F5FB, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` by default. Python 3.13, standard library only, no network.
